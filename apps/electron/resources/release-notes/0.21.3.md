# 最新动态

Storyflow 0.21.3 修复了待回答问题丢失的情况，并改进了对话中的工具和文件操作。

## 对话与工具

- **待回答问题可恢复**：刷新页面、切换项目或重新连接后，仍可继续回答尚未完成的问题，并使用中文提示。
- **技能和数据源更易选择**：输入框加号菜单支持悬停展开技能和数据源，可搜索、查看说明并选择使用。
- **工具详情更简洁**：去掉重复标题和多层卡片，单份内容直接展示，多份输入和输出保留分区标签。

## 文件与侧栏

- **文件右键操作更完整**：对话中的文件链接支持在侧边打开、打开所在位置和复制文件路径，中文路径也能正确处理。
- **侧栏拖拽更平滑**：修复快速调整宽度时的残影，并减淡分隔线。
