# 最新动态

Storyflow 0.21.2 改善了长对话和项目目录的响应速度，并减少了闲置会话的内存占用。

## 对话与搜索

- **回复更早显示**：开始收到正文时即可阅读，长回复生成期间继续输入也更流畅。
- **搜索直达正文**：点击文件搜索结果即可跳到匹配位置，并突出显示命中的内容；连续搜索时，过期查询会及时取消。

## 项目与内存

- **闲置会话更省内存**：自动释放最近未使用的闲置会话进程，再次使用时恢复历史，正在执行和等待确认的任务会继续保留。
- **目录打开更快**：减少首次进入项目时的重复请求，完整目录仍按原有内容显示。
- **读取失败时保护正文**：目录读取失败可以重试，未保存的编辑会保留；重新打开文档失败时也会保留已有正文，避免后续输入覆盖原文件。
