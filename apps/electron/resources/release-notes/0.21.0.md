# 最新动态

Storyflow 0.21.0 更新了模型、Skills、项目文件预览和桌面导航，常用操作更容易找到和完成。

## 模型与 Skills

- **新增 Gemini 3.7 和 3.8 Flash**：登录后的托管模型列表现在提供这两个模型，并支持低、中、高三档思考强度。
- **优先展示最新 Skills**：Skills 页面默认打开全部目录并按发布时间倒序排列，新增内容不再被固定精选遮住。

## 工作区与导航

- **直接预览 JSON 和 PDF**：在项目文件工作区打开这两类文件时，右侧面板会直接显示结构化内容或 PDF 页面。
- **侧边栏更容易调整**：侧边栏新增定时任务入口，宽度可以拖动或用方向键调整，收起侧边栏时会话标题也会保持原位。
- **设置入口各自独立**：个人资料、用量、输入和快捷键现在分别拥有独立页面，账户菜单也可以直达个人资料与用量统计。

## 对话与用量

- **斜杠菜单和空白页更清楚**：输入 `/` 后会显示与输入框同宽的命令菜单，新对话每 10 秒轮播 3 条随机提示。
- **用量热力图继续使用网格**：日、周、月视图可以切换，悬停时会按所选周期高亮整组数据。
- **长对话定位更醒目**：右侧提示点的当前项和切换动效更明显，浏览多轮对话时更容易确认位置。
