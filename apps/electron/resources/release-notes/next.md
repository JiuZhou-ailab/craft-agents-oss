# 最新动态

Storyflow 0.21.1 修复了侧边栏会话排序和项目归属显示，并统一了菜单与对话的视觉样式。

## 会话与导航

- **拖动调整会话顺序**：固定、项目和自由对话都可以上下拖动排序，重新打开后保留调整结果。
- **对话显示所属项目**：从项目中启动的对话会在顶部显示项目名称，方便确认当前归属。
- **一次浏览历史提问**：侧边消息导航更窄，悬停后展示全部历史提问列表，点击即可跳转到对应位置。

## 菜单与外观

- **操作菜单样式统一**：菜单使用一致的字号、间距和高亮，弹层边框更清楚，边缘阴影更轻，侧边栏统一使用默认光标。
- **用户消息更醒目**：消息气泡随明暗主题反转底色和文字，代码、图表和文件标签保持清晰可读。
- **修复 macOS 白色图标**：应用图标恢复完整标识，避免只显示浅色底板。
- **邀请好友更方便**：账户菜单新增邀请好友入口，点击即可复制官网链接并发送给朋友。
